テストと品質管理

コードの品質を保つためのテスト手法とデバッグ方法を学びます。

1. 単体テスト

【ポイント】関数の入出力を検証し、期待通りの動作を確認する単体テストの基本を実践します。 

function add(a, b) {
    return a + b;
}

const test1 = add(2, 3) === 5 ? "成功" : "失敗";
const test2 = add(0, 0) === 0 ? "成功" : "失敗";
console.log("テスト1:", test1);
console.log("テスト2:", test2);

2. デバッグ手法

【ポイント】console.logで実行中の値を確認し、関数の動作を段階的に検証します。 

function calculate(x, y) {
    console.log("入力値:", x, y);
    let result = x * y + 10;
    console.log("計算結果:", result);
    return result;
}

calculate(5, 3);

3. エラーハンドリング

【ポイント】try-catch文でエラーをキャッチし、アプリケーションが正常に動作し続けるようにします。 

try {
    let result = 10 / 0;
    console.log("結果:", result);
} catch (error) {
    console.log("エラーが発生しました");
}

4. パフォーマンス測定

【ポイント】performance.now()で処理時間を計測し、効率の良いコードを書くための指標を取得します。 

const startTime = performance.now();
let sum = 0;
for (let i = 0; i < 1000; i++) {
    sum += i;
}
const endTime = performance.now();
console.log("実行時間:", (endTime - startTime).toFixed(2) + "ms");
