JavaScript

JavaScriptとは？

JavaScript（ジャバスクリプト）は、主にWebページに動きをつけたり、ユーザーの操作に応じて内容を変化させたりするために使われるプログラミング言語です。ブラウザ上で動作し、Web開発において欠かせない存在です。

1. 変数とデータ型

【ポイント】let/constでの変数宣言、数値・文字列・真偽値・オブジェクト・配列の基本的な型を理解します。 

let age = 25;
let name = "田中太郎";
let isStudent = true;
let person = { name: "佐藤", age: 30 };
let colors = ["赤", "青", "緑"];

console.log("年齢:", age, "名前:", name);
console.log("学生:", isStudent, "人物:", person);
console.log("色:", colors);

2. 演算子

【ポイント】四則演算（+, -, *, /）と比較演算子（>, ===）の使い方、論理演算子（&&, ||）による条件判定を実践します。 

let x = 10, y = 3;
console.log("計算:", x + y, x - y, x * y, x / y);
console.log("比較:", x > y, x === y);
console.log("論理:", x > 18 && true);

3. 制御構文

【ポイント】条件分岐（if/else if/else）と繰り返し処理（forループ）で、プログラムの流れを制御します。 

let score = 85;
if (score >= 90) console.log("優秀！");
else if (score >= 70) console.log("良い！");
else console.log("頑張ろう！");

for (let i = 1; i <= 3; i++) {
    console.log(`${i}回目`);
}

4. 関数

【ポイント】function宣言とアロー関数（=>）でコードを再利用可能な部品に分割します。 

function greet(name) {
    return `こんにちは、${name}さん！`;
}
const double = (num) => num * 2;

console.log(greet("山田"));
console.log("5の2倍:", double(5));

5. オブジェクトと配列

【ポイント】プロパティアクセス（.記法）と配列操作（push、インデックス参照）の基本をマスターします。 

let student = { name: "鈴木花子", age: 20, grade: "A" };
let fruits = ["りんご", "バナナ"];

console.log("学生:", student.name, student.age);
fruits.push("オレンジ");
console.log("果物:", fruits[0], fruits);

6. 配列の便利なメソッド

【ポイント】map（変換）、filter（抽出）、find（検索）など、配列を効率的に操作するメソッドを習得します。 

let numbers = [1, 2, 3, 4, 5];
let doubled = numbers.map(num => num * 2);
let evens = numbers.filter(num => num % 2 === 0);
let found = numbers.find(num => num > 3);

console.log("元配列:", numbers);
console.log("2倍:", doubled, "偶数:", evens, "見つけた:", found);

7. DOM操作の基礎

【ポイント】getElementByIdで要素を取得し、textContentやstyleで要素の内容とスタイルを動的に変更します。 

let target = document.getElementById('demo');
target.textContent = "JavaScriptで変更されました！";
target.style.color = "white";
target.style.fontWeight = "bold";
console.log("要素を変更しました");
ここが変わります

8. ES6機能

【ポイント】テンプレートリテラル（`文字列`）と分割代入、スプレッド演算子（...）で、モダンなJavaScriptの記法を使います。 

let userName = "田中", userAge = 25;
let message = `ユーザー: ${userName}, 年齢: ${userAge}歳`;

let user = { name: "佐藤", age: 30, city: "東京" };
let { name, age, city } = user;

let arr1 = [1, 2, 3];
let arr2 = [...arr1, 4, 5];
console.log(message, arr2);

9. 非同期処理（Promise / async・await）

【ポイント】Promiseとasync/awaitで非同期処理を扱い、処理完了後のコールバックを管理します。 

// Promiseの基本
const promise = new Promise((resolve, reject) => {
    setTimeout(() => resolve("処理完了！"), 1000);
});

promise.then(result => console.log(result));

// async/await
async function fetchData() {
    await new Promise(resolve => setTimeout(resolve, 500));
    console.log("データ取得完了");
}
fetchData();
