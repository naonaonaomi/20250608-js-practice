JavaScript ES6+モジュール編

モダンなJavaScriptの機能とモジュールシステムを学習します。
実際のプロジェクトで使われる最新の機能を理解しましょう。

1. ES6モジュール（import/export）

【ポイント】export/importでコードを複数ファイルに分割し、再利用可能なモジュールとして整理します。 

// ES6モジュール例
export function add(a, b) {
    return a + b;
}

import { add } from './math.js';
console.log("加算:", add(5, 3));

2. デフォルトエクスポート

【ポイント】export defaultでモジュールの主要機能を1つだけエクスポートし、インポート時に任意の名前をつけられます。 

// デフォルトエクスポート例
export default class Calculator {
    add(a, b) { return a + b; }
}

import Calculator from './calculator.js';
const calc = new Calculator();
console.log("結果:", calc.add(10, 5));

3. 動的インポート

【ポイント】import()でモジュールを非同期読み込みし、必要時だけロードしてバンドルサイズを最適化します。 

// 動的インポート例
async function loadModule() {
    const module = await import('./math.js');
    console.log("動的読み込み成功");
    return module.add(15, 25);
}

4. Optional Chaining（?.）

【ポイント】?.演算子でプロパティが存在しない場合のエラーを防ぎ、深いネストでも安全にアクセスします。 

const user = { address: { city: "東京" } };
const emptyUser = {};

// Optional Chaining（安全なアクセス）
console.log("都市1:", user.address?.city);
console.log("都市2:", emptyUser.address?.city);

5. Nullish Coalescing（??）

【ポイント】??演算子でnull/undefinedのみをチェックし、0やfalseなどの有効な値はそのまま使用します（||との違いを理解）。 

const config = { theme: null, timeout: 0 };

// ?? 演算子（Nullish Coalescing）
console.log("テーマ:", config.theme ?? "デフォルト");
console.log("タイムアウト:", config.timeout ?? 5000);
